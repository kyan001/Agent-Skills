# Media Organizer

库里的先例优先；本文件的默认值只在新库或库内无先例时使用。库根、类目名和语言都从库画像读取，换一个库只需重做库画像。

## 术语

- **库画像**：库根、库语言、类目、已有写法四项，决定后面每一步的默认值。
- **库语言**：标题、季号、集名和变体词使用的语言。问用户，或取库内已有条目的主流语言。
- **本地标题**：元数据源在库语言下的标题。
- **原名**：`original_title` / `original_name`。
- **元数据源**：提供标题、原名、年份、季/集的数据库，默认 TMDB，可替换。
- **变体**：同一作品的其他语言、音轨或画质，只加后缀，不另开作品目录。

## 工作流

1. **库画像**：确认库根（用户没给就问）和库语言；按「类目」一节读类目名；抽 2-3 个已有条目，记下层级、季号写法、集号写法、变体词。
   完成判据：四项齐全（根、语言、类目、写法），目标父目录已确定且无同名文件。
2. **取名**：查元数据源（默认 TMDB，没工具就开网页或让用户提供，并切到库语言），写出 `本地标题 原名 (年份)`；剧集再记季号、季首播年、集标题。
   完成判据：公式行成立，类型与动画判断有依据。
3. **落位**：按「归档决策」和库画像落位，按「电影文件」「剧集文件」写文件名。
   完成判据：路径每段都能归类。
4. **验收**：跑「验收」断言。
   完成判据：三条全过。

## 类目

列出库根，现有目录名就是类目名，不按本 skill 重构。空库才建默认类目，常见是电影、剧集、动画（按库语言）；动画不需要就并入前两者。纪录片、综艺、演唱会、音乐、漫画等其他媒体，归入现有最接近的类目或库内同类先例；没有先例先问用户，不自建，也不硬套影视公式。

## 名称公式

`本地标题 原名 (年份)`。

- 本地标题与原名相同（单语言库常见）只写一次：`标题 (年份)`。
- 原名缺失时用英文名；两者都没有才退成 `本地标题 (年份)`。
- 年份：电影上映年、剧集首播年、季目录该季首播年；按元数据源，不按记忆改。
- 带年份的层级：单片、单季作品、季目录；多季作品层与系列层不带。
- 清理文件系统不允许的字符（Windows 常见 `\ / : * ? " < > |`）；标题里的 `:` `?` 换成空格；分隔只用空格；扩展名沿用源文件。

## 归档决策

按顺序问：

1. 动画吗？库里有动画类目就进去；没有就按电影或剧集归。
2. 电影还是剧集？
3. 单片/单季还是系列/多季？
4. 库里有同作品或同系列吗？有就沿用它的层级和写法。

| 情况 | 位置 |
|---|---|
| 电影，单片 | `<电影类目>/<文件>` |
| 电影，系列第 2 部起 | `<电影类目>/<系列名 原名>/<文件>` |
| 剧集，单季 | `<剧集类目>/<剧名 原名 (年份)>/` |
| 剧集，多季 | `<剧集类目>/<剧名 原名>/<季目录>/` |
| 动画，库内单列 | `<动画类目>/<国家?>/<按电影或剧集继续>` |
| 多分部节目 | `<剧集类目>/<系列名>/<分部名 (年份)>/…/<季目录?>/` |

- **季目录** = `<剧名> <季号> (年份)`；剧名和季号都按库画像（如 `第N季`、`Season N`、`S<N>`）。
- **平铺**用于单片、单季；**分层**用于系列电影、多季剧、多分部节目。
- 单季平铺少一层；已知会有下一季就直接分层。已在库的单季加季时，把作品目录上提为剧名层，原目录改名季目录，集文件名不动。
- 电影系列：第 2 部进库时建系列目录，第 1 部随之移入。
- 新库季号不补零；库内已有 `第01季` 这类补零写法就沿用。
- 国家/地区子目录只在库已有该细分时使用。
- 其他类型套用最接近的电影或剧集模板，不新造层级。

## 电影文件

单片直接套公式。系列片和特例：

- 系列片：`本地标题 N 原名 (年份).ext`；本地标题有副标题：`本地标题 N：副标题 原名 (年份).ext`。
- 系列编号连续编，不按重启分段。
- **单片双音轨**：电影原声与本地语言配音都留时，为单部建 `本地标题 NN：副标题 原名 (年份)/`，内放无后缀原声与 `- <语言>`；目录号补零，文件名不补。
- 花絮/特典放系列目录，文件名用库语言的特典词（如 `花絮`、`Featurette`）；库里有写法就沿用。

## 剧集文件

- 多季：`剧名 - S01E01 - 单集标题.ext`；单集标题缺失就省尾段。
- 单季：库画像里已有纯数字编号就 `剧名 - 01 - 单集标题.ext`；新库默认 SxxExx。
- 剧名前缀跟库画像：同一类剧用同一种前缀；没有先例时用本地标题，库内同类带原名就再加原名。
- 集标题用库语言；没有就用原名标题，再没有省略。
- 特典：目录名跟库画像（如 `Bonus`、`特典`），没有先例按库语言选词；集号用 `S00E01`，单集特典用 `SxxE00`。
- 多分部：系列 → 分部 → 季；分部只有单季则平铺在分部目录。

## 变体

| 变体 | 电影文件 | 作品/版本目录 | 季目录 |
|---|---|---|---|
| 语言 | 名末 `- <语言>` | 名末 `- <语言>` | 名末 `- <语言>` |
| 多音轨 | 名末 `- <多音轨词>` | 同左 | 同左 |
| 画质 | 名末 `- [4K]` | 名末 `- [4K]` | 目录末 `- [4K]`，且每集名末 `- [4K]` |

- 语言词跟库画像（如 `国语`、`粤语`）；没有先例就用 `- <语言>`。
- 多音轨词按库语言（如 `双语音轨`、`Dual Audio`）。
- 顺序：语言 → 音轨 → 画质，如 `… (2018) - 国语 - [4K].ext`。
- 无后缀是默认音轨；整部只有一条非默认音轨时，也照样打后缀，便于将来并存。
- 季目录已标语言，集文件不重复。

## 改名

只改文件名，不动目录结构、扩展名和内容。

1. 先列 `旧名 → 新名` 清单，标出无法套公式的条目。
2. 用户确认后再改；批量前抽样验证。
3. 目标名已存在时不覆盖，停下问用户。

## 优先级

沿用现有与本规范冲突时：

1. 层级、主标题、编号体系：沿用库画像。
2. 后缀、分隔符、非法字符：新文件按本规范；旧文件不动，除非用户要求整理。
3. 仍拿不准：保持现状，问用户。库内先例互相冲突时，按数量最多的写法；仍不确定就问。
4. 任何命名决定都应能指向库画像里的先例或本文公式；指不出来就停下来问。

## 验收

1. 位置：每个路径段都能归入六类之一：类目、国家/地区、系列名、作品名、`名称 (年份)`、`季目录`；归不进去的段即违规。
2. 名称：文件名能套回公式，年份与元数据源一致，无非法字符、无首尾空格。
3. 编号与变体：同剧只用一种集编号；后缀只出现在上表位置。

## 元数据字段（TMDB 为例）

| 要的 | 字段 |
|---|---|
| 本地标题 | `title` / `name`（库语言） |
| 原名 | `original_title` / `original_name` |
| 年份 | `release_date` / `first_air_date` |
| 季年份、集名 | `season.air_date`、`episode.name`（库语言） |
| 系列 | `belongs_to_collection.name` |

## 严格匹配

默认按本文件命名。需要适配具体播放器的严格匹配时，读 `references/scraping.md`。
