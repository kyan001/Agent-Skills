# 短语分支

## 要求

每个分区独立评估，各自产出候选条目；`### N.` 表示固有优先级，仅决定评估顺序，不输出——最终按重要性跨分区筛出 ≤10 条，按 `../SKILL.md` 的列表项格式输出，分区名用来取标签。

适用：习语、固定搭配、定型句式、谚语；日语则为慣用句 / ことわざ / 四字熟語 / 定型表现。**不能独立成句**的多词单位才走这里，能独立成句的走 `./sentence.md`。

### 1. 释义与读音
* 整体义：整条短语实际表达的意思，不逐词拼合
* 直译对照：字面义与实际义差距大时给出直译（如 break the ice 字面「打破冰面」），差距小时省略
* 逐词释义：短语里的难词、低频词、熟词僻义逐个说明（如 break the ice 的 ice 不指字面的「冰」）
* 读音：英文给整条美式 IPA，并标出重音与弱读（如 give up /ˌɡɪv ˈʌp/ 重音在 up；介词类成分常弱读，如 in front of /ɪn ˈfrʌnt əv/）；日文用假名标注汉字读音、片假名标注外来语原词，约定与 `japanese-lyrics-lint` 一致：`漢字[かな]`、`カタカナ[Origin]`

### 2. 结构与构成
* 字面义 → 引申义的逻辑（如 break the ice：打破初见时的僵硬）
* 固定度：哪些成分可替换、哪些不能（如 depend on 的 on 不可换成 to）
* 句法功能：能作谓语 / 状语 / 定语 / 名词性成分，及能否被拆分、被动化、加修饰语
* 出处：可追溯时给出（航海、军事、圣经、莎士比亚、典故等）

### 3. 常用度与适用地域
* 谁常说：美式 / 英式 / 澳式 / 日式英语；日语再区分关东关西、男女用语、世代差异
* 常用度：日常高频 / 偏书面 / 老派 / 生僻或已过时
* 语域：口语 / 俚语 / 正式 / 粗俗或冒犯
* 地域变体：同一意思在不同地区的不同说法，注明哪一种是主流

### 4. 使用场景与搭配
* 典型语境：用在什么场合、对谁用、什么语气
* 常见句式：常与哪类主语、时态、句型连用
* 常见误用：母语者不会这么用的地方、易混短语

### 5. 触类旁通
* 同语言近义辨析：与最接近的短语在强度、语感、正式度上的差别
* 跨语言对照：日语里对应的惯用表达（如 let bygones be bygones ≈ 水[みず]に流[なが]す），并说明日本人实际用不用、常用到什么程度
* 中文对照：有无对应的成语 / 俗语，能否直译，直译会走味在哪里
* 语感差异：同一意思在不同语言间的褒贬、分量、使用频率差异

### 6. 附加说明（按需）
* 可讲：文化背景、语感变化、母语者的实际使用习惯（通常取 1-2 条；近义辨析归「触类旁通」，不在这里重复）

## 输出样例

输入：`break the ice`

* **释义与读音**：
    * **整体义**：打破初见时的拘谨，让气氛松下来；直译「破冰」，中文已借用
    * **逐词**：break 此处是「打破（僵局）」而非「打碎」；ice 指「拘谨、冷场」，不是字面的冰
    * **读音**：/ˌbreɪk ði ˈaɪs/，the 后接元音读 /ði/，不弱化为 /ðə/
* **结构与构成**：
    * **字面义 → 引申义**：冰面要敲开才能通行 → 打开局面
    * **固定度**：the 不可省；break 可换成 melt，但 break 为主流
* **常用度与适用地域**：
    * **常用度**：英美通用，会议、团建、社交场合高频，未见老派
    * **语域**：中性偏口语，正式场合也能用
* **触类旁通**：
    * **日语**：場[ば]を和[なご]ませる，偏「缓和气氛」，不强调「首次开口」
    * **中文**：借用为「破冰」，多出现在团建、会议议程

输入：`水に流す`

* **释义与读音**：
    * **整体义**：把过去的纠纷、过失当作没发生过，不再追究
    * **逐词**：水[みず] = 水，流[なが]す = 冲走；直译「让水把它冲走」
    * **读音**：水[みず]に流[なが]す
* **结构与构成**：
    * **字面义 → 引申义**：把不快的事丢进河里冲走 → 不再计较
    * **固定度**：助词 に 不可换；可换 流[なが]れる（水に流れる）但不常见
* **常用度与适用地域**：
    * **常用度**：日本全国通用，职场与私人和解都用；偏成熟的说法
    * **语域**：中性偏口语，正式场合也可用
* **触类旁通**：
    * **英语**：let bygones be bygones，同表既往不咎，但更中立、像陈述原则
    * **中文**：「一笔勾销」语感偏交易（多用于账目），不如日语版强调「双方都别再提」
