# dict

目标是**母语思维**：每条解释都服务于「用目标语言思考」，而不是只给中译。输出始终简短（长文本模式的翻译部分除外）。

## When to Use

* 一次处理一个输入单位；一次给多个单位或整段时按 `## 长文本模式` 处理。
* 不适用：明确只要译文、不要讲解；日常对话里顺带出现的英文；非语言素材（代码、日志、URL）。

## Steps

1. **分类**：单词 → `./references/word.md`；短语 → `./references/phrase.md`；句子 → `./references/sentence.md`；整段 / 整篇 / 对话 → `## 长文本模式`。
   判据：单个词走单词分支；多个词构成的固定搭配、习语、定型句式且不能独立成句的走短语分支；单个句子（即使要跳句才能读懂）走句子分支，在释义里注明依赖什么上下文；输入本身含多个单位（整段、整篇、多轮对话）才走长文本模式；拿不准时看用户意图——想理解「这句话」就走句子分支。
   完成标准：能说出走哪条分支或长文本模式，且第 2、3 步只执行该分支（长文本模式按其自身步骤）。
2. **读取对应分支文件**，对**每个分区分别**评估，列出该输入在该分区下真正需要讲的条目；再把各分区的候选条目汇总起来比较，只保留对理解该输入最重要的（含释义，释义永远排第一）。
   完成标准：总条目数 ≤10，且**这是上限、不是目标**——宁可只讲两三条，也不要为凑数把次要内容堆上来：十条已经是相当可观的收获量，再多就是信息淹没。计的是条目（父项下的子项），父项只是分组标签。被砍掉的是价值最低的条目，落在哪个分区都一样——不得因为某分区排在后面就整段舍弃，也不得把各分区条目全部堆上去。
3. **按输出格式排出**。完成标准：输出全部是列表项——分区是粗体父项，条目是它的子项；没有标题层级，也没有独立成行的正文。

## 输入有问题时

* 拼写、时态、语态、搭配、语法有误：先纠错，再照常解析。
* 纠错自成父项，标签 **纠错**，置于所有条目之前，且无条件置顶（早于释义，也早于长文本模式的翻译）——否则用户会先读到译文，把错误当成正确用法记住；翻译按修正后的句子给出。
* **不能只给「A → B」的替换**，每条至少要说清为什么错：是语法规则、固定用法，还是中文的干扰（如「三年了」只有时长，没有 since / for 之分）。给错因比给答案重要。
* 输入是使用者自己写的（日记、作文、邮件、口语稿，或用户说明是自己写的）时，纠错就是本次的主角：每条写足「错在哪 / 为什么错 / 怎么改」三点，并指出是否为母语者常见偏误；此时解释可以写长、可以跨行，不受「每条尽量一行」的限制，也不占用 ≤10 条的讲解额度。
* 非自己写的输入，纠错条目照常计入 ≤10 条。
* 输入本身无误则该项不出现，也不评价、不挑刺。

## 长文本模式

输入是整段、整篇或一整段对话（多个单位）时，三步都要做：

1. **先整体翻译**：分区写成父项 `* **翻译**`，其下每个句子 / 每段 / 每轮对话一个子项；保留原文的段落与说话人结构。
2. **再挑重点讲**：从全文挑最值得讲的少数条目，词、短语、句子都可入选；**每条单独成一个父项，标签用该条目本身**（如 `* **learn the ropes**`），其下按归属分支的条目要求展开子项。只讲真正的难点，不逐句过一遍；翻译项与追问项不计入 ≤10 条，讲解条目仍守 ≤10 条。
3. **最后选项式追问**：父项 `* **要细讲哪个？**`，其下列 2-4 个具体候选（如 `take off` 这个词组 / 第 3 句的虚拟语气 / 这个称呼的语感），让用户直接挑；不要只问「哪里不懂」这类开放式问题。

按挑出的条目读取对应分支文件，可同时读多个：词 → `./references/word.md`，短语 → `./references/phrase.md`，句子 → `./references/sentence.md`。

条目顺序：**纠错**（如有）→ **翻译** → 重点条目 → **要细讲哪个？**。

用户明确要求逐句 / 全部讲时，才逐句展开；此时每个单位各守 ≤10 条与格式规则，不合并不省略。

## 输出格式（各分支共用）

* **只有一种形式**：列表项。不用标题层级（`#` / `##` / `###`），也没有独立成行的正文——叙述与解释一律进列表项。
* **分区写成粗体父项**：`* **分区名**`。内容少时直接跟在冒号后（`* **搭配**：relentless pressure…`），内容多时标签后留空、内容写成它子项。分区名太正式时可换短的（如「构成」→「词根词源」），择短而能认出即可。
* **条目写成子项**：子项缩进一层，再分层就继续缩进；子项内部仍可用行内粗体标注细节（`* **词根**：…`）。
* **粗体只出现在列表项里**（作父项标签或行内标签），不充当标题层级，也不独自成行。
* `### N.` 的编号与各类括号补充（如「（词根词缀）」「（按需）」）都不出现；标为「按需」的分区没有可讲内容时整条不出现。
* 每条尽量一行放得下（纠错的三点式、翻译项除外）。

## 输出样例（长文本模式）

输入：

```text
A: I've been working here since three years.
B: Really? How's it going?
A: So far so good. But I'm still learning the ropes, I guess.
```

输出：

* **纠错**：第 1 句 since three years → for three years —— since 接时间点，for 接时间段
* **翻译**：
    * A：我在这儿工作三年了
    * B：是吗？干得怎么样？
    * A：目前还行，不过我还在熟悉门道，大概是吧
* **learn the ropes**：
    * **义**：摸清一个岗位或行当的门道，不是字面的「学绳子」
    * **构成**：源自船上水手学认绳索 → 熟悉本职流程
    * **常用度**：英美通用、日常高频，略偏口语
* **I guess**：
    * **语用**：句末弱化语气，表示不确定或不想把话说满，读音轻而快
    * **语域**：美式口语常见，正式书面少用
* **要细讲哪个？**：
    * `So far so good` 这类固定说法怎么用？
    * 第 1 句为什么用 I've been working 而不是 I work？
    * A 的 `But` 除了转折，还带了什么语气？
